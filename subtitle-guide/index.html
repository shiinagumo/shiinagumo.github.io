CHAPTER 01

安装与配置工具

只需要安装两款主要软件。语音识别、字幕校对和双语排版都可以通过图形界面完成。

工具用途入门建议
Subtitle Edit语音识别、调轴、SRT 校对先安装
AegisubASS 双语样式与精细排版必装
Subtitle Edit ↗Aegisub ↗

Windows 安装顺序

  1. 安装 Subtitle Edit，打开视频并熟悉字幕列表、波形和保存 SRT 的方式。
  2. 安装 Aegisub，在菜单 Subtitles → Styles Manager 中查看样式管理器。
CHAPTER 02

Whisper 日语识别与人工听校

使用 Subtitle Edit

  1. 打开本地视频文件。
  2. 在 Video → Speech to text 中选择可用的 Whisper 识别引擎。
  3. 设置语言为 Japanese，任务为 Transcribe（转录），不要选择翻译成英语。
  4. 首次按软件提示下载模型，先从可流畅运行的模型测试。
  5. 识别完成后保存为 episode.ja.raw.srt。

原文检查清单

对照音频逐条检查：否定形式、助词、角色称呼、重叠说话、喊叫、背景音乐误识别，以及一句话被切成多个不自然片段的情况。校对后另存为 episode.ja.checked.srt。

1
00:00:03,200 --> 00:00:05,400
今日は何をするつもり？

2
00:00:05,800 --> 00:00:07,600
まだ決めてないよ。

不要跳过日语听校。翻译模型可能把错误的日文识别结果翻译得非常流畅，但那并不代表它忠实于原台词。

CHAPTER 03

AI 翻译：从日语 SRT 到中文 SRT

最容易入门的方法是把已经校对的 SRT 按剧情场景分批交给 ChatGPT。每批先试 30～60 条，避免长输出造成漏行或错位。

可直接复制的翻译提示词

你是一名专业的日语动漫字幕翻译。
请把以下日语 SRT 翻译成自然、准确的简体中文。

要求：
1. 严格保留每条字幕编号、时间轴与条目数量。
2. 中文符合人物性格、语气与上下文，避免机械直译。
3. 处理敬语、口癖、省略、双关和文化背景时忠实原意。
4. 人名、地名和专有名词保持统一。
5. 不编造原文没有的信息。
6. 先输出完整中文 SRT，再列出需要人工复核的编号。

角色与术语表：（在这里填写）
前情概要：（在这里填写）

以下是日语 SRT：
（在这里粘贴字幕）

翻译示例

日语可能的中文字幕
今日は何をするつもり？今天打算做什么？
まだ決めてないよ。还没决定呢。
しょうがないな。真拿你没办法。

翻译完成后另存为 episode.zh.srt。应检查中文是否与日语逐条对应、人物称呼是否统一、是否出现无依据的补充信息。像 しょうがないな 这样的表达需要根据语境决定译法。

两轮审校

  1. 准确性：对照日文检查漏译、误译、否定、人物关系。
  2. 可读性：压缩冗长句子，优化断行，保留原有语气。
CHAPTER 04

Aegisub：制作双语 ASS 字幕

建议采用日语在上、中文在下的双层字幕。日文和中文分别作为独立 ASS 事件，使用不同样式，后续修改更加方便。

今日は何をするつもり？
今天打算做什么？

样式示意，实际字体大小取决于 ASS 脚本分辨率和播放器。

手工操作

  1. 在 Aegisub 中打开 episode.ja.checked.srt，再通过 Video 菜单打开视频、通过 Audio 菜单载入音频。
  2. 在 Subtitles → Styles Manager 新建 JP 与 ZH 两个样式。
  3. 日文样式使用较小字号，中文使用较大字号；均使用底部居中、描边与适当阴影。
  4. 复制日语字幕事件，保持时间轴一致，将复制的事件改为 ZH 样式并替换为对应中文。
  5. 保存为 episode.bilingual.ass，播放检查。
